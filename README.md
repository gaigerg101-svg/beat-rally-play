# Beat Rally

A 3D browser table tennis rhythm game: a song always plays and every hit lands on its beat.

**Play:** https://gaigerg101-svg.github.io/beat-rally-play/

Works best in a desktop Chromium browser (Chrome or Edge) with a mouse. Click once to start the audio. Swipe the
mouse through the ball on the beat; hold the right mouse button to angle the blade.

This repository holds only the built game. Music, sounds and fonts are used under their licences, listed in
THIRD_PARTY_NOTICES.md and in the game's Credits screen.
